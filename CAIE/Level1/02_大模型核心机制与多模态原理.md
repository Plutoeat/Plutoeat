# 大模型核心机制与多模态原理

## 神经网络与深度学习基础

### BP (Back Propagation，反向传播) 神经网络

通过误差反向传播传播算法训练的多层前馈神经网络。能够学习输入数据与输出结果之间的映射关系，无需预先以数学公式描述该映射

#### 网络结构

- **输入层（Input Layer）**：负责接收外部数据，将输入数据传递给隐藏层。不做实质性计算——相当于神经网络的"感觉器官"
- **隐藏层（Hidden Layer）**：位于输入层与输出层之间，可有一层或多层。网络的"深度"即由隐藏层数量决定。每一层通过激活函数对数据进行变换，逐层提取更抽象的特征。可以理解为网络的"思维加工中枢"
- **输出层（Output Layer）**：接收隐藏层的处理结果，通过特定函数将其转换为最终预测输出（如分类概率、回归数值）

#### 工作原理

- **前向传播（Forward Pass）**：输入数据从输入层流经隐藏层，逐层计算，直至输出层产生预测结果

- **误差计算**：将预测结果与真实答案对比，计算损失函数（Loss Function）

- **反向传播（Backward Pass）**：误差从输出层**反向**流向输入层，计算每个神经元的权重对误差的贡献（即梯度）

- **权重更新**：依据梯度和学习率，通过梯度下降法调整所有连接权重，减小误差

重复上述步骤，直到误差收敛至可接受范围

#### 局限

处理图像是效果不佳。缺乏CNN的**局部连接**和**权值共享**机制，导致参数量庞大、效率低下

### CNN(Convolutional Neural Network, 卷积神经网络)

专为处理具有空间结构的数据设计的深度神经网络

#### CNN VS. BP神经网络

| 特性           | BP神经网络（全连接网络）           | CNN（卷积神经网络）                          |
| :------------- | :--------------------------------- | :------------------------------------------- |
| **连接方式**   | 全连接（每个节点连接所有下层节点） | **局部连接**（每个神经元只感知局部区域）     |
| **权值**       | 每个连接有独立权重，参数量极大     | **权值共享**（同一卷积核在整幅图上共用参数） |
| **空间信息**   | 不保留（展平为一维）               | 保留（二维空间结构完整）                     |
| **平移不变性** | 无                                 | 有（同一物体无论在图中的哪个位置都能被识别） |

**局部连接**：每个神经元只与输入图像的一个局部区域（感受野）相连，而不是与整幅图像全连接。这既保留了图像的空间局部信息（相邻像素高度相关），又大幅减少了参数数量

**权值共享**：同一个卷积核（一组权重参数）在输入图像上**滑动**扫描，对每个局部区域做相同的特征提取运算。这意味着无论"猫耳朵"出现在图片左上角还是右下角，同一个"耳朵检测器"都能识别它（平移不变性）

#### 网络结构

- **卷积层（Convolutional Layer）**：用卷积核提取局部特征，生成特征图（Feature Map）
- **激活层（Activation，如ReLU）**：引入非线性，增强模型表达能力
- **池化层（Pooling Layer）**：下采样，减小特征图尺寸，保留显著特征，降低计算量（最大池化/平均池化）
- **全连接层（Fully Connected Layer）**：网络末端，将提取的特征映射到最终的分类/回归输出

#### 应用场景

*边缘检测*是CNN早期任务之一，旨在识别图像中物体边界的像素位置。经典算法包括基于梯度的Sobel算子、Prewitt算子，以及效果更佳的Canny算法（高斯滤波→梯度计算→非极大值抑制→双阈值检测）。这些传统算法在CNN出现后被深度学习方法大幅超越

*目标检测*在识别类别的基础上还需定位物体位置（用边界框标注）。经典深度学习检测框架包括两阶段方法（R-CNN系列：先提候选区域，再做分类和定位）和单阶段方法（YOLO系列：一次前向计算同时完成分类和定位，速度更快，适合实时场景）

### 循环神经网络(RNN, Recurrent Neural Network)与长短期记忆网络(LSTM, Long Short-Term Memory)

**RNN**：RNN是专为处理**序列数据**设计的网络结构，其核心特点是：网络存在**循环连接**，上一时刻的隐藏状态会作为输入参与下一时刻的计算

**RNN的核心缺陷——梯度消失（Gradient Vanishing）**：在处理长序列时，早期时刻的信息要经过多次梯度反向传播才能传回来，梯度值在每次传播中都被反复压缩，最终趋向零，导致模型无法有效学习长距离依赖关系

**LSTM**：LSTM是为解决RNN梯度消失问题而设计的改进架构，引入了**三个门控机制**和专门的**细胞状态（Cell State）**

**LSTM 结构**

- **遗忘门（Forget Gate）**：决定"应该从之前的记忆中遗忘哪些信息"，输出0~1之间的值（0=完全遗忘，1=完全保留）
- **输入门（Input Gate）**：决定"当前时刻的哪些新信息应该被记住"，筛选并更新细胞状态
- **输出门（Output Gate）**：决定"当前细胞状态中的哪些信息应该输出"，形成当前时刻的隐藏状态

## EMbedding、Token与Transformer

### Embedding

**One-Hot编码（早期方案）**：词表中每个词用一个维度为词表大小的向量表示，对应词的位置为1，其余全0。缺点：词表有100000个词时每个向量维度就是100000维，极度稀疏；且任意两个词的向量正交（余弦相似度为0），无法表达语义关系

**Word Embedding（改进方案）**：通过训练神经网络（如Word2Vec、GloVe），将每个词映射为低维稠密向量（如128维、256维），使**语义相近的词在向量空间中距离更近**

![Screenshot 2026-04-16 at 12.04.27](/Users/paidaxing/Documents/code/githubProjects/Plutoeat/CAIE/Level1/assets/Embedding.png)

> Embedding技术不限于词语，任何离散对象都可以通过训练映射为连续向量——包括句子、段落（Sentence Embedding）、图像（Image Embedding）、用户行为（User Embedding）。多模态模型的核心之一便是将不同模态的数据（文本、图像）映射到**同一语义向量空间**，从而支持跨模态检索与融合。

### Token

**Token（词元）** 是大语言模型处理文本的基本单位。Tokenization（分词/分词元）是预处理过程：将原始文本切分为Token序列，再将每个Token转换为对应的Embedding向量后输入模型

Token的划分粒度不是固定的词语，而是由**子词（Subword）分词算法**（如BPE、WordPiece）决定的。例如"unhappy"可能被切分为"un"和"happy"两个Token；中文"人工智能"可能被切分为"人工"、"智"、"能"三个Token（具体取决于模型的词表）

**Token数量的实际意义**：大语言模型的上下文窗口、计费单位、推理速度都以Token为单位计量。常用估算规则：英文约4个字符≈1 Token，中文约1.5~2个汉字≈1 Token

### Transformer架构与注意力机制

Transformer由Vaswani等人于2017年提出（"Attention Is All You Need"）

#### 自注意力机制（Self-Attention）

自注意力机制是Transformer的核心。它允许模型在处理序列中每个位置的信息时，同时考虑**整个序列中所有其他位置**对当前位置的相关度，计算出各位置之间的注意力权重，再据此加权融合信息

#### 位置编码（Positional Encoding）

自注意力机制本身不感知词序（对"我爱你"和"你爱我"的处理完全相同），因此Transformer在输入层添加**位置编码**，为每个Token的向量注入其位置信息，使模型能区分"我"在哪个位置、"你"在哪个位置

#### 上下文窗口与长文本限制

大语言模型能同时处理的最大Token数量称为**上下文窗口（Context Window）**。当生成内容的长度接近或超出上下文窗口时，模型的位置编码无法有效表示超出范围的位置关系，自注意力机制对早期内容的"关注力"将显著下降，导致模型在生成长文时出现**"遗忘"早期内容、前后自相矛盾或无意义重复**的现象——这是LLM生成长文稳定性差的底层原因

### 大语言模型的训练与微调

**预训练（Pre-training）**：LLM首先在规模极大的无标注文本数据集（中英文网页、书籍、代码等，通常数万亿Token）上进行自监督学习。训练目标通常是"给定前N个Token，预测第N+1个Token"（语言模型任务）。这一阶段让模型学习语言的语法、语义、事实知识和逻辑推理能力，是整个训练流程中计算量最大的部分

**指令微调（Instruction Fine-tuning / SFT）**：预训练模型只是"文字续写机器"，需通过在标注的"指令-回复"数据集上进行有监督微调，使其学会"遵从人类指令"的行为模式

**基于人类反馈的强化学习（RLHF）**：通过收集人类对模型输出的偏好评价（哪个回答更好），训练奖励模型，再用强化学习进一步优化LLM，使其输出更符合人类偏好，同时减少有害内容输出。这是使LLM变得"更有用、更无害、更诚实"的关键步骤

## 生成模型: GAN 与 扩散模型

### GAN(Generative Adversarial Network, 生成对抗网络)

其核心思想源于博弈论中的**零和博弈**，由**生成器（Generator）**和**判别器（Discriminator）**两个神经网络组成，通过对抗训练相互进化

#### 训练过程

1. 生成器接收随机噪声，生成假图像
2. 判别器同时接收真图像和假图像，判断真伪
3. 根据判别器的反馈，生成器调整参数，生成更逼真的图像；判别器也更新参数，提高鉴别能力
4. 两者交替优化，直到生成器产生的图像让判别器无法区分真伪

#### 优势与缺陷

GAN生成速度快（一次前向计算即可生成），在小面积修补任务中效果极佳（如填充小范围破损区域）。局限是对**大面积、结构性内容缺失**的生成能力不足——GAN倾向于"复制周围纹理"进行填充（纹理蔓延），而非理解整幅画的全局语义来推断缺失区域应该长什么样。例如人物面部大面积缺失时，GAN常生成结构错乱的内容，而非一张符合逻辑的完整脸

**常用GAN变体**：DCGAN（深度卷积GAN）、StyleGAN（高质量人脸生成）、Pix2Pix（条件图像转换）、CycleGAN（无配对数据的风格迁移）

### Diffusion Model(扩散模型)

扩散模型基于物理中的热力学扩散过程，通过"加噪→去噪"两阶段实现高质量图像生成。目前主流的文生图模型（Stable Diffusion、DALL-E 3、Midjourney的核心架构）均基于扩散模型

1. **前向扩散（加噪阶段，训练时使用）**：按照预设的时间步长，逐步向真实图像中添加高斯噪声，经过T步后图像变成纯噪声。此过程是确定性的数学操作，不涉及学习
2. **逆向去噪（生成阶段，推理时使用）**：模型学习"从噪声到干净图像"的逆向过程——在给定文本条件的引导下，从纯噪声出发，每步预测并去除一点噪声，经过T步逐渐重建出高质量图像

**扩散模型和GAN对比**

GAN的判别器给予"真/假"的全局反馈，生成器并不需要真正"理解"整幅画的逻辑。因此，面对大面积空白时，GAN通常以"复制邻近纹理"来填充，这在局部看起来合理，但无法保持全局的语义一致性（会出现纹理重复、结构错乱）

扩散模型的去噪过程在整个图像的**全局像素分布**上进行，模型在数十亿张图像上学会了"一幅完整图像的各部分应该如何相互配合"。当某个区域完全缺失时（被噪声覆盖），模型会"读懂"画面剩余部分的语义上下文——如察觉到脖子、头发、服饰等线索，推断出应该生成一张符合整体逻辑的人脸——拥有基于全局语义的**推断与重构**能力

## 高级架构

### MOE(Mixture of Experts, 混合专家模型)

混合专家模型（Mixture of Experts，MOE）是一种通过**条件计算**（Conditional Computation）在保持巨大参数量的同时控制每次推理计算量的深度学习架构

#### 核心组件

MOE层由 **多个专家网络（Expert Networks）** 和 **一个门控网络（Gating Network / Router）** 组成：

- **专家网络**：若干结构相同但参数独立的前馈神经网络（如32个或64个），通过训练各自发展出对不同类型输入的专长
- **门控网络（路由器）**：轻量级网络，接收每个Token的表示，计算该Token应被路由到哪些专家，输出一组归一化的路由权重（通常只选择Top-K个专家，如Top-2）

![Screenshot 2026-04-16 at 12.36.38](/Users/paidaxing/Documents/code/githubProjects/Plutoeat/CAIE/Level1/assets/MOE.png)

#### 路由坍缩（Routing Collapse）问题与辅助负载均衡损失

MOE训练中存在一个典型问题：门控网络在梯度下降优化过程中，可能发现"把所有输入都路由给某一个或少数几个专家，Loss下降最快"，从而形成"偷懒走捷径"的习惯——大多数专家未被充分训练，模型的多专家能力被严重浪费，这就是**路由坍缩**。

**解决方案：辅助负载均衡损失（Auxiliary Load Balancing Loss）**：在训练目标函数中额外加入一个惩罚项，量化各专家负载的不均匀程度。当门控网络试图将大量请求堆积给少数专家时，这个额外惩罚项会使总Loss上升。如此，梯度下降在优化"预测准确性"的同时，也被迫维持各专家之间的负载均衡，从根本上在数学层面阻止路由坍缩的发生。

### Multimodal(多模态融合)

多模态模型能够处理和理解**多种类型的数据**（如文本、图像、音频、视频），并将来自不同模态的信息融合，实现跨模态的理解和生成

#### 跨模态建模核心：统一语义空间

不同模态数据的原始格式截然不同（像素值/Token序列/波形），要实现融合，需将各模态数据映射到**同一语义向量空间**（Shared Semantic Space）。如CLIP模型将图像和文字分别编码为等长向量，并通过训练使"相互描述的图像-文字对"在向量空间中距离趋近，从而支持"以文搜图"或"以图搜文"

#### 多模态融合策略

- **早期融合（Early Fusion）**：在特征提取阶段就将各模态的原始或浅层特征拼接合并，后续统一处理
- **晚期融合（Late Fusion）**：各模态独立深度处理，仅在最终决策层进行融合（如取均值、拼接后分类）
- **交叉注意力融合（Cross-Attention）**：以一种模态作为Query，另一种模态作为Key和Value，通过注意力机制让不同模态信息相互"对话"——这是目前主流多模态大模型（如LLaVA、GPT-4V）采用的主要方式

## 交互式应用

### 弱交互应用

基于**预设规则和固定流程**驱动

典型场景：

- **AI作业批改**：依据预设评分标准，对学生提交的答案进行自动判评，给出标准化评语
- **知识点问答**：根据用户提问，检索并返回预设知识库中的对应内容
- **自动生成练习题**：基于知识点描述，自动生成不同难度的题目和标准答案

### 强交互应用

AI能够**实时感知对话状态**、**动态调整策略**，与用户进行多轮深度交互的应用模式

典型场景：

- **AI模拟面试**：根据岗位要求模拟面试官，依据候选人的回答内容实时调整追问方向和难度，进行5~10轮对话后给出综合评估
- **AI心理咨询辅助**：在多轮对话中收集情绪信号，动态调整共情策略和引导方向
- **AI角色扮演**：长期维持特定角色人设，在复杂场景中保持角色一致性和故事逻辑连贯性

## 大模型训练

### Catastrophic Forgetting(灾难性遗忘)

将预训练好的通用模型放在单一领域任务的数据上进行全量微调（Full Fine-Tuning）后，模型在目标任务上虽然表现提升，但在其他领域的能力却显著下降的现象

**成因**：神经网络的权重是通过梯度下降在整体数据上调整的。当训练数据分布极度偏向单一任务时（如只有法律文本），梯度更新会系统性地将权重推向对这类输入的最优化方向，破坏了原来为其他任务（如代码、数学、多语言）优化的权重配置

**缓解方法**：

1. **混合数据微调**：在专业任务数据中混入10~30%比例的通用任务数据，防止模型过度偏向单一分布
2. **控制微调强度**：使用较小的学习率和较少的训练步数，让模型"小幅度适应"而非"彻底重塑"
3. **参数高效微调（PEFT）**：见下节
4. **产品层分流**：通过路由机制，根据任务类型决定调用专业微调版本还是基础通用版本，避免单一微调版本承担所有任务

### 参数高效微调

一类不对模型主干参数做全量修改、只训练少量额外参数的微调技术，在保持原有能力的同时适配新任务。最具代表性的是 **LoRA（Low-Rank Adaptation）**

**LoRA的核心原理**：在原有的权重矩阵旁并联一个小的低秩矩阵（由两个远小于原矩阵的矩阵乘积构成），训练时只更新这个小矩阵，原始权重冻结不变。推理时将低秩矩阵与原始权重合并，对外行为与全量微调模型一致
